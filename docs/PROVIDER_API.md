# Provider extension v1 (development contract)

Obtain active host Star `astrbot_plugin_third_party_platforms`; call `host.third_party_register_provider(instance, manifest)`. Duplicate IDs, incompatible versions, unknown capabilities and public credential fields reject registration. Registration creates no login/task/write. Providers must not start independent autonomous planning loops. Install-order/reload/unregistration coordination remains a release concern; stop/close during host shutdown is implemented.

Instance: id matches [a-z][a-z0-9_]{0,63}; capabilities subset browse/search/reply/private_reply/comment/dynamic/owner_share/listen; async status(account), close(); async browse(account,options) for browse, search(account,query,limit) for search, execute(account,action,params,idempotency_key) for write/listen capabilities. Only advertise methods that actually work. Return normalized Content with namespaced source/identity/evidence/modality and Receipt(succeeded|failed|unknown, external_id, code). Platform acceptance without a confirmed external id must not be invented as success. No automatic write retry on timeout/unknown. Shared policy/claim/quota runs before writes; platform implementation still enforces its transport rules.

Optional request_login(account)->{url,expires_at}, poll_login(account)->{state}, poll_events(account,cursor_callback)->[(stream,[Incoming],new_cursor)], reply_context(Incoming)->{text,images,image_attributions,warnings}. Provider must validate image URLs and public-host DNS before returning images. Keep identity and thread author attribution explicit. Incoming.actor_verified reflects platform identity evidence, never privilege. Host rejects external admin commands and does not fabricate QQ events.

Manifest: {api:1,name:display_name,fields:{key:{type:string|int|float|bool|list,description,default?,min?,max?}}}. Maximum32 fields; bounded strings/lists/numbers; bool does not pass numeric validation. Token/cookie/device/signing/session fields forbidden here. These are non-secret account options, not credentials. Host validates and stores values at account.browse.provider_options and passes them inside browse options; UI renders fields when editing that provider. Configuration survives real AstrBot reload. Credentials belong only in per-provider/account SecretStore, never manifest, config, Content, logs or state. A provider may be constructed with host.secrets + host.config by its trusted registering plugin; do not open other providers' accounts.

Host owns scheduler, shared evidence evaluation/attribution, thresholds, permissions/budgets/locks, action and delivery receipts, learning and public-memory gateway. Future provider owner sharing defaults to configured private QQ route. Bili DM/comment-specific routes stay with the Bili provider. Generic memory scopes beyond initial public Bili/XHH must be deliberately added to the independent memory facade; unknown scope reports unavailable, no direct DB fallback.

Providers may optionally expose `action_timeouts: dict[str, float]` for operations that include real-time sessions. The music adapter declares `{"listen": 3600}` to cover up to 1800 seconds of audio and bounded model/network work. Other actions and executor-supplied network operations keep the default 45-second timeout. A timeout remains an unknown receipt with no automatic replay. Scheduler handlers may return a Receipt; its state is persisted on the task rather than treating any normal return as success.
