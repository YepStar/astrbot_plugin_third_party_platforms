# 新旧版功能对照（0.2.0）

这是第一版整合，方便与保留的旧插件比较。旧 B站 AI Bot、小黑盒适配器只停用，不删除；原配置和数据仍在。

| 功能 | 第三方平台首版 |
|---|---|
| B站、小黑盒登录和内容浏览 | 已接入，可分别管理账号与来源 |
| B站热门、首页推荐、分区与特别关注 | 已接入 |
| 小黑盒真实分区与回退分类 | 已接入原版探测、勾选多分区、分类筛选；真实分区全部请求失败时才回退 |
| 存储管理 | 按平台统计、到期正文压缩预览与执行；幂等、配额、去重和日程记录保留 |
| 全天自主安排、学习时段偏好 | 统一管理，允许重叠、跨午夜与休息时间 |
| 内容评分、给主人分享 | 统一评分门槛、配额、间隔和去重 |
| 评论、@ 与 B站私信回复 | 新的隔离回复流程，沿用各账号开关和身份范围 |
| B站文字动态 | 已接入，需单独授权；本机原设置关闭，迁移后仍关闭 |
| 公共记忆 | 接入并行记忆分支；私信不写入公共分支 |
| 网易云自主听歌 | 支持调度接管，需要在新插件为网易云账号启用；手动播放与一起听仍归音乐插件 |
| 自然语言查改日程、查询公开内容 | 接入自然意图分析及原生工具 |
| 小黑盒原生 AstrBot 平台事件、旧会话、候选评论审批面板 | 首版采用独立隔离回复流程，未复刻原事件链和审批面板；旧候选及会话映射随备份保留 |
| B站视频画面分析 | 已迁入 FFmpeg 抽帧和视觉模型分析；保留字幕优先、文字不足时抽帧，也可设为始终分析画面。抽帧无音频，不能宣称完整看过视频 |
| B站视频直读、音频理解、图片/视频动态 | 尚未完整迁入；本版动态先支持文字 |
| B站点赞、投币、收藏、关注 | 已接入独立开关、评分和每日配额；本机原开关保持关闭 |
| B站直播弹幕、番剧 | 尚未迁入；在原版设置对照中标明，旧插件和数据保留 |
| 旧版情绪、人物画像、周期总结、自我演化等 | 不直接复制独立记忆系统；是否保留表达层功能可在对比后决定 |
| 旧版各条专用聊天指令 | 尚未逐条复刻；已提供新工作台和统一工具 |

本机切换保留已有浏览、评论、分享和私信权限。迁移时导入已用配额、历史发送记录和已读内容，避免重新计算配额或自动重发旧消息。旧版发送结果不明的待处理消息留待核对。

对比旧版前：先在新工作台暂停，再停用新插件，然后按需启用旧插件及原小黑盒机器人连接。不要同时运行两套主动浏览。新插件也会检查旧插件是否重新启用，并阻止后续写入。
