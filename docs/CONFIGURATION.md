# 配置与原版对照

总览以 24 小时事件环与今日事件列表并排展示实际日程，不把取消、替换记录混进当前安排。平台日程里的“计划变更历史”仍可查看这些记录。配置、模型或可用平台变化会触发规划；同一平台、账号、活动和时段不变时复用原事件，而非取消后重复新建。人工取消、人工调整、已执行事件不被重规划覆盖。

B站设置按原版思路分为账号连接、基础设置、私信、视频分析、安全与工具、回复权限、主动互动。已接入原有回复概率、冷却、白名单、过滤、上下文、私信范围与数量、补充提示词、阶段模型、视频池与特别关注、每轮及每天视频数、评论和分享、抽帧，以及点赞/投币/收藏/关注开关与评分配额。互动默认关闭；投币每次使用1枚硬币，收藏写入默认收藏夹。

全局自主规划、时间窗、统一预算、公共人格与评分通过“打开全局配置”管理。模型由 AstrBot 提供商管理；页面不会暴露密钥或 Cookie。公共经历写入并行记忆分支；平台消息不能获得 QQ 私人上下文或管理员工具权限。

小黑盒浏览来源保留真实分区探测、搜索与多选（最多20项）、真实帖子流验证、兼容分类多选与全部互斥。已选真实分区优先，成功返回空列表也不触发回退；只有未选分区或全部请求失败时才按保存分类读取推荐流。

账号连接展示昵称、UID、账号元信息、检查时间、运行状态、绑定主人和今日执行统计；B站额外展示头像、等级、硬币和会员。平台未提供的字段明确留空，不根据配置标识编造。

存储页只在预览并确认后压缩到期且已结束的收件正文。凭据、发送回执、幂等键、配额、已读去重、学习数据、日程、待处理事件和记忆发件箱均保留。共用数据库大小与按平台计数分别标注。旧插件数据库和目录继续保留，本页不清理旧插件。

## 尚未完成的一对一迁移

直播、追番、关注动态巡视、部分图像/视频动态与直读、情绪/好感和旧版工具全集等仍不等同于原版。它们没有被认定为“已由其他插件接管”而删掉；页面“原版设置对照”逐项标记已接入、统一管理或尚未接入，保留旧插件作为对照依据。仅恢复可实际生效的开关，不提供保存后无作用的假配置。
