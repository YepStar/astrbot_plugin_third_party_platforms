# 配置与原版对照

总览的“重新生成日程表”只重排今天剩余时段，保留已完成、进行中、人工安排与人工取消；失败时保留原计划。

一行时间窗只表示允许活动的范围，同一窗口可以安排多轮。全局“每轮参考时长”决定候选轮次的长度，窗口边界处可缩短；轮数仍受每日上限约束。平台权重留空表示根据人设、活跃度和学习记录自主选择；填写 0–100 的相对权重，越大越容易被安排，0 不自动安排该平台。权重是挑选倾向，不保证每天次数严格按比例。

总览以 24 小时事件环与今日事件列表并排展示实际日程，不把取消、替换记录混进当前安排。平台日程里的“计划变更历史”仍可查看这些记录。配置、模型或可用平台变化会触发规划；同一平台、账号、活动和时段不变时复用原事件，而非取消后重复新建。人工取消、人工调整、已执行事件不被重规划覆盖。

B站设置按原版思路分为账号连接、基础设置、私信、视频分析、安全与工具、回复权限、主动互动。已接入原有回复概率、冷却、白名单、过滤、上下文、私信范围与数量、补充提示词、阶段模型、视频池与特别关注、每轮及每天视频数、评论和分享、抽帧，以及点赞/投币/收藏/关注开关与评分配额。互动默认关闭；投币每次使用1枚硬币，收藏写入默认收藏夹。

全局自主规划、时间窗、统一预算、公共人格与评分通过“打开全局配置”管理。模型由 AstrBot 提供商管理；页面不会暴露密钥或 Cookie。公共经历写入并行记忆分支；平台消息不能获得 QQ 私人上下文或管理员工具权限。

小黑盒浏览来源保留真实分区探测、搜索与多选（最多20项）、真实帖子流验证、兼容分类多选与全部互斥。已选真实分区优先，成功返回空列表也不触发回退；只有未选分区或全部请求失败时才按保存分类读取推荐流。

账号连接展示昵称、UID、账号元信息、检查时间、运行状态、绑定主人和今日执行统计；B站额外展示头像、等级、硬币和会员。平台未提供的字段明确留空，不根据配置标识编造。

存储页只在预览并确认后压缩到期且已结束的收件正文。凭据、发送回执、幂等键、配额、已读去重、学习数据、日程、待处理事件和记忆发件箱均保留。共用数据库大小与按平台计数分别标注。旧插件数据库和目录继续保留，本页不清理旧插件。

## 尚未完成的一对一迁移

直播、追番、关注动态巡视、部分图像/视频动态与直读、情绪/好感和旧版工具全集等仍不等同于原版。它们没有被认定为“已由其他插件接管”而删掉；页面“原版设置对照”逐项标记已接入、统一管理或尚未接入，保留旧插件作为对照依据。仅恢复可实际生效的开关，不提供保存后无作用的假配置。

## 0.3.0 B站补齐与二次判断

- 账号连接：登录自动续期、检查周期、登录/模型持续异常通知。二维码登录保存续期凭据；缺少凭据时明确提示重新扫码，不能伪造续期成功。提醒默认关闭，启用后每种问题每天最多提醒一次。
- B站私信：分析视频后回复、视频/UP只读搜索、结果数、活跃/空闲监听周期。支持BV链接、受限展开的b23短链与原生视频卡片；不会给私信授予日程管理或任意工具权限。
- 基础设置：看片前候选预筛选、近期真实观看兴趣搜索、兴趣统计范围、关注动态图文和每日条数。关注动态在统一浏览轮次内执行，与视频共用每轮总条数；支持QQ/站内私信推荐，不对动态执行视频投币、收藏、评论。动态默认只看特别关注，旧配置关闭的仍保持关闭。
- 视频分析：长视频采样分段长度、最多采样段数；总画面不超过12张，覆盖间隔较远的片段。属于稀疏画面证据，没有音频，不代表连续看完整段视频。整段视频直读和音频仍在待判断列表。
- 活动回顾：按需查看最近24小时、7天的实际评分、行为状态统计与兴趣，不新增自动投递或独立记忆库。定时感想、图片卡片仍待判断。
- 全局：按实际模型提供商累计调用失败、冷却后仅允许一个探测请求，不自动重发已经不确定的发送动作。

原版设置对照默认展示“需要你判断”，按功能分组，支持搜索及查看已接入/统一管理映射。74个确定不再迁移的配置从在线对照中移除，清单见 `MIGRATION-REVIEW-0.3.0.json`；保留旧插件源码、配置和历史数据供回退。54个待判断配置不是功能开关，不会把未实现能力显示为已生效。

### 二次判断选择

原版设置对照中每项提供“尚未选择 / 接入 / 不接入”，每组有批量选择按钮。选择自动保存，顶部显示进度及保存状态，也可点击立即保存。选择记录位于现有平台数据库 settings 的 `bili_migration_review` 键，包含 revision、choices、updated_at；通过已鉴权的 page/state 返回 `bili_migration_review` 可读。它不会修改插件配置、权限、预算或日程，也不会自动执行尚未实现功能。54项全部选完后，可据此进行后续实现。多页面版本冲突时拒绝旧页面覆盖。

## 0.4.0 按选择完成迁移

“生活与总结”配置临时浏览情绪、陪伴活动同步、自主动态及日报/周报。自主动态只使用真实公开浏览证据，受统一日程、全局轮数、账号动态权限、每日上限、间隔和发送防重约束。日报/周报支持仅归档、QQ、B站文字动态或两端；中文卡片使用系统中文字体或指定字体，字体不可用时发送文字。自动功能继承旧开关，默认不会因为选择接入就启动。活动回顾提供手动生成归档和查看记录。

“安全与工具”提供公开/私信拉黑与保护名单、可信域名、恶意证据累计阈值及告警。该累计不是关系好感度；仅记载有确切原文证据的恶意事件。自己、主人和配置的保护名单始终不自动拉黑，失败/不确定动作不重发。B站专用查询工具只读公开资料/公共记忆；互动工具仅授权主人私聊可调用，且不绕过已有账号权限、评分或配额。私信不能调用日程管理或任意QQ工具。

“视频分析”可选Qwen/Gemini兼容视频直读格式、模型提供商、模型名与帧率。只有实际传入媒体且返回有效观察才标记直读/音频观察；不可用时回退稀疏画面，明确没有音频。直读下载最多32MB，请选择支持该格式的模型。私信图片与动态附图可以使用独立AstrBot图片模型提供商，不创建第二套API凭据。
