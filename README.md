# 冷月系—第三方平台

把 B站、小黑盒等平台放进同一个工作台，让机器人按自己的安排浏览内容，挑选值得分享的发现，并在你允许的范围内互动。

目前已接入 B站和小黑盒。迁移后先停用旧插件、保留原数据，方便对比；视频直读、旧版专用指令等差异见[功能对照](docs/COMPARISON.md)。

可以做什么：

- 分别登录机器人账号，管理每个平台的浏览和互动设置。
- 阅读字幕，配合抽取视频画面交给视觉模型分析，再按实际依据评价内容。
- 用统一评分挑选内容，只分享达到你设定标准的发现。
- 安排全天活动，允许时间重叠，并逐渐记住不同时间的内容偏好。
- 通过「自然意图分析」用日常说法查看、调整活动安排。
- 连接「并行记忆分支」，保存公开阅读经历；
- 连接「网易云音乐」，统一安排自主听歌。

## 使用

在 AstrBot 用本仓库地址安装，配置模型，再从「（月）第三方平台」查看总览，在顶部切换平台，进入「账号连接」添加账号并扫码登录。总览可重新生成今日剩余日程；同一时间窗可以安排多轮，全局可选填平台权重，不填则自主规划。平台详细策略在二级分页设置。先检查登录与浏览设置，再启动自主活动。抽帧需要 FFmpeg 和可识别图片的视觉模型。

## 网易云音乐联动

搭配 [网易云音乐 1.4.8](https://github.com/YepStar/astrbot_plugin_netease_browser) 使用第三方平台插件 0.2.3 或更高版本即可统一安排听歌，无需本地补丁。音乐插件继续负责真实播放、QQ 一起听提议及确认、房间生命周期；统一平台负责日程与对外行为评分。

听歌会话包含选曲、实时播放及听后决策，独立使用最长一小时的执行预算。普通平台网络动作仍为 45 秒；超时或结果未知时不会自动重发，日程会保留真实执行状态。一起听提议仍取决于音乐插件开关、每日额度、角色决策以及适用的统一评分，不保证每次听完都邀请。

两仓库放在同一目录时，运行 `python -m pytest tests/test_music_execution.py` 可额外验证真实音乐调度接口、播放完成、邀请决策和评分门控的联动；未安装音乐源码时仅跳过这两项联动测试。

## 来源与致谢

本插件参考并提取了两款插件及其本机定制版本的代码。它们是初始平台接入的重要基础：

- [B站 AI Bot](https://github.com/chenluQwQ/astrbot_plugin_bilibili_ai_bot)，作者 **chenluQwQ、claude**：贡献了 B站接口与扫码登录、视频内容读取、FFmpeg 抽帧与视觉分析、评分、主动浏览、评论/私信/动态相关实现，以及自主规划、行为预算和内容偏好机制。
- [小黑盒适配器](https://github.com/674537331/astrbot_plugin_xiaoheihe_adapter)，作者 **RyanVaderAn**：贡献了小黑盒接口与登录、请求签名、帖子和分区读取、通知/评论流程、多账号隔离、权限校验、事件去重与发送状态管理。

原 MIT 许可证与作者声明保留在源码中。YepStar 负责冷月系整合、通用核心的迁移。具体提取范围见[开发状态](docs/DEVELOPMENT.md)与[源码审计清单](docs/source-audit.json)。

实际可用能力取决于各平台接口和账号状态。现有小黑盒接入并不是稳定的官方开放自动化 API；接口变化时会停止相关操作并明确报告，不保证永久可用。
